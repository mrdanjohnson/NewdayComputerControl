# MacControl OTA signing keys — DEVELOPMENT ONLY

`ota_dev.pem` / `ota_dev.pub.hex` are the **development** ECDSA P-256 key pair
for the signed dual-partition OTA feature (spec 15.3). They are generated by
`../scripts/ota_sign.py keygen --out keys/ota_dev` and are **committed to this
repository on purpose** so any developer (and the AT harness) can sign test
images.

**PRODUCTION DEVICES MUST USE THEIR OWN KEY.** This private key is public
knowledge the moment it sits in git; any holder can sign firmware your devices
will accept. For a production fleet:

1. `python scripts/ota_sign.py keygen --out <your-prefix>` on a private
   machine (never commit the result).
2. `./.venv/bin/python scripts/ota_sign.py pubheader --key <your-prefix>.pem
   --out src/ota_pubkey.h` to embed the public key.
3. Keep the private key in your signing infrastructure only.

The compiled-in public key lives in `../src/ota_pubkey.h` (generated; do not
edit by hand). Container format and CLI usage are documented at the top of
`../scripts/ota_sign.py`.
